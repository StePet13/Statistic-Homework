5. Theoretical Context: Derivation Pipeline and Ethereum Standards

Cryptographic Standards

Mnemonic & BIP-39

BIP-39 standardizes deterministic seed generation. Initial entropy (e.g., 128-256 bits) generates a 12-24 word mnemonic phrase from a standard dictionary. The PBKDF2 function (with HMAC-SHA512 and 2048 iterations) derives the master seed from the phrase and an optional passphrase, ensuring portability and security against dictionary attacks.

Key Derivation (BIP-32 / BIP-44)

The master seed feeds the HD (Hierarchical Deterministic) BIP-32 scheme, allowing child key derivation. BIP-44 defines a standardized path (e.g., m/44'/60'/0'/0/0 for Ethereum), organizing the cryptographic tree by purpose, coin type, account, and index, keeping funds logically separated but recoverable from a single root.

Keccak-256 vs SHA3-256 & Address Derivation (EIP-55)

The private key, a scalar on the secp256k1 curve, generates an uncompressed public key (64 bytes, X and Y coordinates). Ethereum applies the Keccak-256 hash function (standardized before NIST's final modifications to SHA3-256) to the entire public key. The final address consists of the last 20 bytes (40 hex characters) of the hash. EIP-55 implements a mixed upper/lowercase checksum mechanism by verifying the string address hash to prevent typographical errors.
