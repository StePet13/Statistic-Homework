Critical Discussion (One-Way Function vs Cryptographic Hash):

The empirical results of this dashboard demonstrate the fundamental differences between an algebraic one-way function (ECC) and a PRF (Pseudo-Random Function / Hash).
  • Preserved Algebraic Structure (No Pure Avalanche): The Avalanche test clearly shows that changing a single bit of $k$ does not cause the output to change chaotically (flipping ~50% of the bits). Changing the LSB of $k$ is equivalent to algebraically adding or subtracting $G$.
  • Security based on Computational Hardness: In a perfect Hash, no polynomial statistical test should be able to distinguish the output from a random sequence. In ECC, a trivial polynomial test like verifying the equation $Q_1 + Q_2 = Q_3$ immediately reveals the underlying algebraic structure.
  • Separation of Concerns in Ethereum: This is why Ethereum doesn't rely solely on the elliptic curve. It uses ECC for signing (where the algebraic homomorphism is necessary for the ECDSA algorithm), but then it "hashes" the resulting public key through Keccak-256 to destroy the algebraic structure and ensure a true Avalanche Effect before generating the final address.
